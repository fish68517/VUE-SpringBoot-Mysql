# 服务端接口约定（预留）

客户端允许在首页填写完整接口地址，例如：

```text
https://server.example.com/api/v1/call-screen-records
```

每形成一条采集记录，`CallRecordUploader.upload()` 都会被调用一次，并使用 `POST` 发送 `application/json; charset=utf-8`。接口为空时仍进入上传模块并打印 JSON，但不会联网。

请求头：

```text
Content-Type: application/json; charset=utf-8
Accept: application/json
X-Install-Id: <应用首次运行生成的随机 UUID>
```

请求体示例：

```json
{
  "recordId": "7b741293-bb09-47ce-a774-39d551f40d01",
  "installationId": "1f5a7c22-25db-4d03-8afe-e8ee9035364b",
  "phoneNumber": "13800138000",
  "isMarked": true,
  "markCount": 23,
  "markType": "疑似诈骗",
  "sourcePackage": "com.android.dialer",
  "capturedAt": 1790143200000,
  "rawTextLines": ["来电", "138 0013 8000", "被23人标记", "疑似诈骗", "接听", "拒绝"],
  "androidVersion": "16",
  "sdkInt": 36,
  "deviceModel": "Google Pixel 9",
  "appVersion": "1.0.0"
}
```

建议服务端返回 HTTP 200～299。客户端会在状态页展示响应结果；非 2xx、超时和网络异常均会写入 `CallMarkUpload` 日志。

正式部署建议使用 HTTPS，并根据业务要求增加令牌、签名、重试队列和数据脱敏。本示例没有预置任何真实服务器密钥。
