# 消防（Fire）业务接口文档

本地URL** http://192.168.112.165:11001/api/boot/system/fire

## 基础信息

- **Base URL**: `{host}/api/system/fire`
- **通用响应格式**: `DxResponse<T>`
- **分页响应格式**: MyBatis-Plus `Page<T>`（含 `records`、`total`、`size`、`current`、`pages` 字段）
- **分页请求参数**: `SafeQueryAo`（所有 POST 分页接口通用请求体）

---

## 通用请求体 SafeQueryAo

| 字段名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| pageNumber | Integer | 是 | 页码（从 1 开始） |
| pageSize | Integer | 是 | 每页条数 |

---

## 通用分页响应结构 Page\<T\>

| 字段名 | 类型 | 说明 |
|--------|------|------|
| records | Array\<T\> | 当前页数据列表 |
| total | Long | 总记录数 |
| size | Long | 每页记录数 |
| current | Long | 当前页码 |
| pages | Long | 总页数 |

## 附录二：通用 DxResponse 响应结构

```json
{
  "code": 200,
  "message": "success",
  "data": { ... }
}
```

- 非分页接口：`data` 为对应的 DTO 对象
- 分页接口：`data` 为 MyBatis-Plus `Page<T>` 对象，结构如下：

```json
{
  "code": 200,
  "message": "success",
  "data": {
    "records": [ ... ],
    "total": 100,
    "size": 20,
    "current": 1,
    "pages": 5
  }
}
```
