# 演示账号配置

| 角色 | 账号 | 密码 | 范围 |
| --- | --- | --- | --- |
| 管理员 | admin | Demo123! | 全部区域、调度、验收与重置 |

其余操作员见 `users.json`，角色见 `roles.json`，动作权限见 `permissions.json`。登录页的身份快捷选择读取这里的 JSON，不维护第二套密码。

均为虚构演示凭据，编译后可被查看，不存放真实账号、第三方密钥或 Android 签名密码。修改后重新校验、构建，并按需要重置本机状态。
