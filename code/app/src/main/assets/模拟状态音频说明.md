# 模拟状态内置 MP3

将以下八个真实 MP3 文件直接放在本说明所在目录（`code/app/src/main/assets/`），不要另建子目录。文件名均为小写，区分大小写。放入后需要重新构建并安装 APK，无须在 App 中选择文件。

| 下拉框状态 | 文件名 | 播放时机 |
| --- | --- | --- |
| 正常接通 | simulation_connected.mp3 | 响铃等待后进入接通状态时播放一次；自动挂断时长优先，到时会停止音频 |
| 正在通话中 | simulation_busy.mp3 | 响铃等待后播放忙线提示，不进入接通状态 |
| 无人接听 | simulation_no_answer.mp3 | 自动挂断/等待时长超时后播放 |
| 暂停服务 | simulation_suspended.mp3 | 响铃等待后播放 |
| 无法接通 | simulation_unreachable.mp3 | 响铃等待后播放 |
| 语音留言 | simulation_voicemail.mp3 | 响铃等待后播放留言提示（不新增录制留言功能） |
| 关机 | simulation_powered_off.mp3 | 响铃等待后播放 |
| 对方拒接 | simulation_rejected.mp3 | 响铃等待后播放 |

## 行为与兼容

- 优先播放“本地媒体”中手动选择的对应音频；没有选择或音频不可读/无法播放时，回退到上表内置 MP3。
- 想使用内置文件，清除对应手动音频即可。恢复默认媒体只清除用户配置，不删除内置文件。
- 两种来源都不可用时跳过声音，不阻断状态流转；非接通状态短暂显示后结束。
- 非接通状态按所播放音频的实际时长等待结束，不再固定 1.3 秒截断声音。
- 正常接通音频若长于自动挂断时长，会在挂断时停止；要播放完整请调大自动挂断时长。
- 所有音频只播放一次，不循环。非接通状态保留真实结果码，通话时长为 0。
- 彩铃开关控制彩铃视频/音频，不关闭这些模拟状态提示音。
- 构建配置明确不压缩 MP3，播放器通过 assets 文件描述符读取音频及其时长。
