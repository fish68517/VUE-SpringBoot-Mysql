# 5—8 分钟答辩演示路线

## 演示前准备

1. 启动 MySQL。
2. 启动 Spring Boot，确认 `/api/home/overview` 返回成功。
3. 启动 Vue，打开首页。
4. 准备账号 `admin/admin123` 和 `zhangsan/123456`。

## 演示流程

### 1. 首页与技术架构（约 40 秒）

展示区域数、站点数、桩总数、空闲、使用中和故障指标。说明系统采用 Vue 3 + Spring Boot + MySQL，地图使用高德 JS API，图表使用 ECharts。

### 2. 地图和站点详情（约 1 分 20 秒）

进入“站点地图”，按区域或关键字筛选，点击地图 Marker 和左侧站点卡片。进入详情查看营业时间、服务设施、桩状态，再打开站内二维导览。

### 3. 区域统计（约 50 秒）

进入“区域统计”，切换区域和日期范围，介绍使用率柱状图、每日趋势折线图以及数据库统计快照。

### 4. 普通用户闭环（约 1 分钟）

使用 `zhangsan/123456` 登录，收藏一个未收藏站点。进入个人中心查看收藏，提交一条简短反馈。

### 5. 后台管理（约 2 分钟）

切换到 `admin/admin123`，展示工作台和十个固定管理模块：

1. 在充电站管理中修改营业时间或站点名称。
2. 在实时状态管理中新增一条状态，或点击“运行一次状态模拟”。
3. 在反馈处理中打开刚才的反馈，填写回复并设为“已完成”。
4. 在区域统计中选择当天并点击“重新生成统计”。

### 6. 前后台同步（约 50 秒）

返回前台刷新站点详情和个人中心，展示站点资料、桩状态和反馈回复已经同步变化，说明 Vue 页面、Spring Boot 接口和 MySQL 已形成完整闭环。

## 稳定性建议

- 演示站点地址解析前先填完整的“城市 + 区县 + 道路”。
- 自动定时模拟默认关闭，避免讲解过程中数据自行变化。
- 演示删除时不要删除已有站点；可新增一条临时站点后再删除。
- 答辩前完整走两遍流程，不在现场批量录入数据。
