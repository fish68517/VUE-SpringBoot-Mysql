# Web UI 美化修改思路

## 当前界面问题

- 用户、医师、管理员页面主体背景偏空，内容区域和空白区域对比弱，截图中的页面容易显得单调。
- 部分页面表单和卡片横向铺得过宽，阅读路径不够集中。
- 导航、表单、表格字号偏小，长时间录入健康数据时不够醒目。
- 各角色页面已有不少卡片和表格样式，但缺少统一的视觉基调。

## 修改目标

- 在用户端、医师端、管理员端统一增加健康医疗主题背景图，并通过透明度控制避免遮挡页面元素。
- 统一提升基础字号、页面标题、导航项、表单标签、输入框和表格文本的可读性。
- 调整内容最大宽度、卡片间距、卡片阴影、圆角和半透明背景，让页面不再大片空白。
- 不改动业务接口、路由、表单字段和数据逻辑，主要通过全局样式覆盖完成。

## 实施方案

1. 下载医疗健康相关静态图到 `VUE/src/assets/health-system-bg.jpg`，作为系统背景素材。
2. 新增 `VUE/src/styles/ui-polish.css`：
   - 给用户、医师、管理员三个布局加统一背景伪元素；
   - 使用 `opacity` 和半透明遮罩降低图片干扰；
   - 统一主内容区域最大宽度、边距和透明卡片；
   - 放大导航、标题、表单、表格、按钮等常用组件字号；
   - 保持响应式规则，移动端减少内边距和字号。
3. 在 `VUE/src/main.js` 引入全局样式，使所有角色页面生效。
4. 对 `UserLayout.vue`、`DoctorLayout.vue`、`AdminLayout.vue` 的主区域和导航进行轻量补强，确保背景层和内容层层级清晰。

## 预期效果

- `/user/profile`、`/user/health-data`、健康趋势、健康历史、咨询等用户页面会有统一的医疗背景和更清晰的卡片结构。
- `/doctor/patients`、数据审核、健康建议、患者档案等医师页面会沿用同样的背景和字号规范。
- `/admin/users`、统计、审计日志等管理员页面会减少纯白空白感，表格和图表卡片更突出。
- 页面业务功能保持不变，只优化视觉与排版。
