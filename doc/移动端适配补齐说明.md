本次完成移动端源码补齐及本地验证。按照本次要求，没有执行 H5 发行构建、App 发行构建、APK 打包或 uniCloud 上传。已有发行目录和已安装 APK 不包含本次修改，不能用旧包判断新功能是否生效。

## 1. 手机与 Web 的功能分工

两端继续复用设施、任务、工单 ID、权限规则和本地业务引擎；手机具有独立工作台、导航、列表和地图交互。

| 功能 | 本次实现 |
| --- | --- |
| 启动与登录 | 将实际首个启动页面修正为登录页。App 进入移动工作台；H5 宽度小于 900 像素使用移动界面，桌面默认进入运行大屏。App 横屏仍按移动客户端处理。 |
| 底部导航 | 工作台、任务、地图、我的四个入口。详情具有返回和工作台入口；一级入口切换重建页面栈，避免不断堆叠。 |
| 个人工作台 | 待执行巡检、已完成巡检、本人工单数量；本人待办、现场业务快捷入口和公告。访客仅显示可读入口。 |
| 我的任务与总览 | 本人任务卡片、完成率、搜索、待执行/进行中/历史分类、检查进度、任务地图和轨迹入口。取消任务不计入完成率分母。管理员可显式切换区域任务。 |
| 本地任务发布 | 复用任务发布与检查规则，操作员仅能新建本人任务；检查结果和说明必填，完成任务后进入历史记录。 |
| 移动地图 | 收起式筛选、底图切换、管线显隐、缩放/复位、点选/矩形框选、结果卡片、底部详情抽屉。任务地图只展示任务检查设施及两端都关联该任务的管线。 |
| 地图关联操作 | 设施详情、关联告警、现场上报、设施及管线纠错；保留设施编号、任务编号。框选数量只计算当前任务及筛选范围内的设施。 |
| 事件与时间上报 | 填写设施、标题、描述、北京时间发生时间，建立工单并进入详情。发生时间独立于工单创建时间，支持重载和快照保存；非法日期拒绝提交。 |
| 阀门与简单编辑 | 设施详情保留阀门状态切换的二次确认；纠错提交既有六级审核，审核通过前不修改有效台账。移动操作员编辑页不显示新增/删除操作选择。 |
| 历史与轨迹 | 历史任务查看检查记录、任务地图和轨迹；轨迹继续使用已有播放、暂停、倍速和进度控制。没有轨迹的新任务显示无记录，不生成虚构 GPS 轨迹。 |
| 工单、告警详情 | 移动列表使用卡片，告警详情独立呈现；共享业务详情切为单列、可换行按钮及触控尺寸。 |
| 我的账号 | 账号、角色、负责区域、个人工作入口、版本和退出登录。管理工具仅对管理员显示；手机个人页不再直接呈现场景重置及回放时钟设置。 |

手机直接打开桌面的门户、巡检列表、地图和设置入口时，会转入相应移动页面并保留查询参数。合法详情回跳继续保留；外部或未注册的登录回跳地址会被拒绝。

## 2. 使用流程

1. 登录操作员账号，进入个人工作台。打开“任务”，按待执行、进行中或历史查看本人巡检。
2. 点击任务卡片“任务地图”，查看该任务关联设施。点击地图设施或结果卡片，打开详情抽屉。
3. 点击“事件上报”，填写标题、描述和发生时间，例如 `2026-09-19 08:35`。提交后进入工单详情，分别显示发生时间和创建时间。
4. 工单详情返回地图时恢复原页面。上报成功后已替换上报页，返回不会重新打开已提交的表单。
5. 回到任务填写检查项并提交完成，在“历史巡查”查看结果。新任务没有历史轨迹时显示无记录。
6. 进入阀门设施详情，确认后切换本地状态；从设施或管线抽屉提交纠错，在申请记录中查看审核进度。

管理员需要管理区域任务时，使用“我的 → 管理工具 → 区域巡检与分派”。操作员和访客不显示管理配置入口，手机直接访问相关配置路由也会被拦截。

## 4. 如何查看这次修改

在项目 `code` 目录打开终端：

```powershell
npm run dev:h5
```

按终端实际输出访问开发地址。本次使用 `http://127.0.0.1:5173/web/`，将浏览器宽度调为手机尺寸，再登录。原来的 `4173` 发行预览读取已有构建，本次没有更新它。

保持开发服务器运行，在另一个终端执行：

```powershell
npm run test:mobile
```

脚本默认访问上面的 5173 地址；端口不同时，可先设置 `$env:MOBILE_URL = 'http://127.0.0.1:实际端口/web/'`。脚本需要本机 Chrome 和项目已有 Playwright 依赖。

## 5. 源码位置与验证边界

主要新增文件：

- `code/layouts/MobileLayout.vue`、`code/styles/mobile.scss`：移动端外壳和跨组件适配样式。
- `code/components/MobileHome.vue`、`MobileTasks.vue`、`MobileProfile.vue`：三个独立移动页面主体。
- `code/platform/client.ts`、`code/navigation/clientPolicy.ts`：客户端识别、入口映射及导航归属。
- `code/domain/event-time.ts`：发生时间有效性规则。
- `code/scripts/browser-mobile.mjs`、`code/tests/mobile-navigation.test.ts`、`code/tests/mobile-report.test.ts`：自动化回归。

现有 `PageHost.vue` 根据客户端选用外壳；地图、任务、告警、工单、设施和上报组件继续复用领域规则。发生时间是工单可选字段，旧记录不需要补填，也不会为旧工单伪造发生时间。

本次适配使用本地数据、示意坐标和本地状态控制。2026-09-22 追加修改已为移动地图接入高德真实底图，原管网视图仍使用示意坐标，见[移动端高德地图修复说明](移动端高德地图修复说明.md)；没有新增 GPS、设备控制或跨设备自动同步。Android 系统返回键关闭地图抽屉已加入代码，但系统返回键、真实触控、状态栏安全区、后台恢复、原生文件与视频表现尚需真机验证。H5 和单元测试不能替代 Android 真机验收。
