# 第二阶段使用与数据维护说明

版本：`2.0.0-phase2`，数据版本：`phase2-20260921-v1`。工程为 `code` 中的普通 uni-app Vue 3 项目，34 个页面共用本地状态。所有设备、地图位置、轨迹、视频与业务记录均为演示数据。

## 1. 启动与升级

在 `code` 目录执行 `npm ci`、`npm run build:h5`、`npm run preview`，打开 `http://127.0.0.1:4173`。开发模式使用 `npm run dev:h5`。登录页提供管理员、操作员、访客入口；账号密码仅在 `code/account` 维护。

检测到第一阶段 `phase1-20260920-v1` 的本机数据时，保留设施、告警、工单、任务和历史，补充第二阶段默认配置，再统一校验。之后首次保存会写入升级后的状态。其他未知版本或损坏数据不会被自动覆盖：管理员可检查记录后重置。建议升级前通过浏览器开发工具保留第一阶段存储副本，升级后通过“门户、通知与快照”导出正式快照。

## 2. 地图管理与六级审核

1. “管控一张图”支持拖动、缩放、底图和管线开关。选择“矩形框选”并拖出区域；选择“多边形面选”逐点点击，至少三个顶点后点击“完成面选”。设施按区域包含关系筛选，管线按与区域相交关系筛选。点击“清除区域选择”恢复。
2. 选择设施或管线，点击“点线编辑与纠错”。支持新增、编辑、删除。设施使用本地示意坐标；管线可编辑起终点、管径和折线路径，起终点坐标以关联设施为准。
3. 提交后生成申请，有效台账保持不变。管理员逐级填写审核意见并通过第 1—6 级，第六级才生效。移动设施同时更新连接管线端点。提交人可修改驳回申请并重新提交，从第一级开始，旧历史保留。
4. 审核配置有六个节点。目前账号数据中只有一个管理员，因此默认由同一管理员分别完成六次审核；新增演示管理员后可配置不同审核人。已有申请冻结提交时的节点配置。
5. 被管线、设备、任务、工单、路线或爆管样例引用的设施不能直接删除。已有区域业务关联的设施不能直接跨区域或 DMA 迁移。已生效对象发生变化时，旧申请终审会拒绝覆盖，需驳回后重新提交。
6. “图层配置”依次执行保存草稿、模拟同步、模拟发布。已发布字段显示在地图设施详情的“已发布图层字段”。全流程仅修改本地配置。
7. “爆管影响分析”展示固定影响设施、建议关闭阀门和模拟户数，可定位管线、查看设施并导出清单。它是预设关联分析，不是实际水力计算。

“操作日志”支持搜索和 CSV 导出，页面显示最近 200 条，导出包含全部匹配记录；操作员只看自己的日志。

## 3. 巡检模板、路线、改派与回放

- 从巡检台账进入“模板与路线”。模板字段支持文本、数值、单选和必填配置。基础检查结果、检查说明始终必填。新模板使用新编号；发布任务时保存模板副本，后续配置不改变旧任务。
- 路线绑定一个区域和按选择顺序排列的设施。发布任务可选择预设路线或自选设施。管理员可分配区域内操作员；操作员只能为自己创建本人区域任务；访客不能创建。
- 任务详情填写模板字段、检查结果、说明，并可选择本地附件。异常检查项自动生成关联维修工单，重复上报不重复生成。任务完成不会自动关闭维修工单。
- 管理员可填写原因后改派或取消任务。改派只调整巡检执行人，已创建的异常维修工单保留原执行人。取消后历史和维修工单保留，任务不再进入完成率分母，也不能继续上报。
- “人员、轨迹与统计”支持播放、暂停、1/2/4 倍速度、时间滑块、回到起点和人员切换。离开页面停止回放。初始任务有固定演示轨迹，新建任务没有虚构实时定位，未配置轨迹时显示空态。
- 里程采用示意坐标每单位 10 米的约定；时长取轨迹首末时间差。工作量按当前可见有效任务统计，不作为真实考勤或定位记录。

## 4. 设备、采样、能耗与 DMA

设备详情进入“采样、启停与能耗”，设置 1—300 秒整数采样间隔，以及模拟开机/关机。状态变化生成带模拟时间的启停事件。设备详情点击“播放模拟采样”，每 5 秒推进 60 秒模拟时间，按各设备间隔生成确定性压力信号；离线设备不产生新样本。全局保留最近 3,000 个样本，单设备曲线最多显示 120 个。切页、退出及应用隐藏会暂停时钟。

“能耗与设备运行”支持日期、日报/月报、运行时长曲线和节能方案。启停时长按北京时间区间交集计算，并截断到当前模拟时间；功率和电表是预先配置的完整日样例，与即时压力采样分开展示。能耗优先电表增量，无电表时对相邻功率做梯形积分；超过一小时的间隔、倒退电表和没有覆盖的区间不补造数据。方案按预设系数比较能耗，压力仅作为约束。

DMA 详情可配置漏损率阈值（百分数输入），查询历史起止日期。净供水不大于零时不绘制漏损率，不把无效分母当作 1。“DMA 漏损”预设场景使典型分区超过阈值；其余场景可从演示设置重置。

综合报表提供用水、压力、能耗、运行时长、巡检、管网变更六类日报/月报和 CSV 导出。巡检按计划日期展示当前完成状态；管网按第六级审核生效时间统计新增、修改和删除；未生效申请不计入。无样本或无变更的时段展示空态。

## 5. 门户、通知、视频与快照

- “门户、通知与快照”可以增加、隐藏、上移门户卡片，每个用户单独保存。
- 通知可配置短信/邮件渠道和告警等级。手动触发或告警受理时只生成匹配渠道、等级的本地“仅模拟发送”记录，不发真实消息。
- 视频中心有单画面/多画面切换、两个可播放通道和一个离线通道。两个在线通道使用同一段原创合成泵房示意视频，支持实际播放与循环；离开页面移除播放器。没有摄像头连接。
- 管理员导出 JSON 快照后可在另一设备导入同版本文件。导入先校验，再替换本机业务状态；格式错误、非法引用、超 8 MB 文件以及凭据字段会被拒绝，原状态保留。快照不包含账号、密码、登录会话。
- H5 导出会下载实际 CSV/JSON 文件。App 代码使用应用私有 `_doc` 目录，保存成功后显示路径；“读取快照文件”读取 `_doc/智慧供水快照.json`，也可直接粘贴内容。跨设备文件转移由用户完成，不会自动同步。App 文件操作仍需真机验证。

## 6. 移动端操作

底部导航提供工作台、任务、地图、我的。工作台进入事件上报；选择设施并填写标题和描述后创建实际本地工单，时间取模拟时钟。阀门详情支持确认后模拟切换开启/关闭并记录日志。地图可框选、面选，设施纠错通过同一六级审核流程。本人任务可新建、上报、查看历史及轨迹。所有移动操作均不请求 GPS、真实阀门或外部业务系统。

## 7. 数据与代码维护位置

| 位置（相对 `code`） | 用途 |
| --- | --- |
| `data/facilities.json`、`pipes.json`、`dma.json`、`devices.json` | 基础有效设施、管线、分区与设备；唯一默认来源 |
| `data/inspection-templates.json`、`inspection-routes.json` | 模板字段和预设区域路线；唯一默认来源 |
| `data/phase2.json` | 审核节点、图层、通知、节能方案、爆管关系、视频索引、轨迹、启停、电表功率与 DMA 历史样例 |
| `data/metrics` | 第一阶段用水和完整日压力样例 |
| `data/assets/pump-demo.mp4` | 原创合成本地视频，构建时复制到 `static/demo-assets` |
| `data/manifest.json` | 数据版本和默认场景 |
| `account` | 演示账号、角色、权限；不进入快照 |
| `services/mock/phase2-engine.ts` | 第二阶段权限、事务、审核和配置逻辑 |
| `domain/phase2.ts`、`reports.ts`、`validate-phase2.ts` | 几何、指标、报表和导入校验 |
| `components/MapManagement.vue`、`InspectionTools.vue`、`OperationsPanel.vue`、`VideoPanel.vue` | 新增领域界面 |

页面保存不会修改上述源 JSON。修改源文件后运行 `npm run check`、`npm test`，重新构建；本机已有状态需先备份再重置才能采用新默认数据。不要直接修改 `static/demo-assets` 或发行目录作为数据源。
