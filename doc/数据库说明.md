# 汽车充电桩平台数据库说明

## 1. 基本信息

- 数据库：MySQL 8.x
- 数据库名：`charging_platform`
- 本地账号：`root`
- 本地密码：`root`
- 字符集：`utf8mb4`
- 建表脚本：`springboot/src/main/resources/sql/schema.sql`
- 初始化数据：`springboot/src/main/resources/sql/data.sql`

Spring Boot 启动时会按顺序执行建表和初始化脚本。脚本使用 `CREATE TABLE IF NOT EXISTS`、`INSERT IGNORE` 和不存在判断，可重复启动。

## 2. 数据表

| 表名 | 主要用途 | 关键关联 |
| --- | --- | --- |
| `sys_user` | 普通用户和管理员 | `user_type` 仅用于前端入口区分；密码明文 |
| `region` | 省、市、区县 | `parent_id` 自关联 |
| `charging_station` | 充电站资料与经纬度 | `region_id -> region.id` |
| `charging_pile` | 充电桩设备 | `station_id -> charging_station.id` |
| `pile_realtime_status` | 充电桩状态快照 | `pile_id -> charging_pile.id` |
| `charging_usage_record` | 模拟使用记录 | 关联充电桩和用户 |
| `region_statistics` | 每日区域统计 | `region_id + stat_date` 唯一 |
| `user_favorite` | 用户收藏 | `user_id + station_id` 唯一 |
| `user_feedback` | 用户意见和管理员回复 | 关联用户 |
| `guide_point` | 站内导览比例坐标 | 关联站点 |
| `notice` | 公告、维护和提示 | `create_by -> sys_user.id` |

## 3. 状态字典

- 充电桩工作状态：`0空闲、1使用中、2预约、3离线、4故障`。
- 站点状态：`0停用、1运营、2维护`。
- 用户状态：`0禁用、1正常`。
- 用户类型：`0普通用户、1管理员`。
- 反馈状态：`0待处理、1处理中、2已完成`。
- 公告状态：`0草稿、1发布、2下架`。
- 充电记录状态：`0进行中、1完成、2异常`。

## 4. 统计口径

- 当前状态取每个充电桩 `pile_realtime_status.id` 最大的一条。
- 区域使用率：`使用中充电桩数量 / 区域充电桩总数 × 100%`。
- 日使用次数和充电量按 `charging_usage_record.start_time` 所在日期汇总。
- 后台“重新生成统计”使用 MySQL `ON DUPLICATE KEY UPDATE`，同一区域同一天不会重复生成。

## 5. 删除规则

- 区域下存在充电站时不能删除区域。
- 充电站下存在充电桩时不能删除充电站。
- 用户、区域、站点、充电桩和公告采用逻辑删除。
- 状态、记录、统计、导览点和反馈为普通记录删除。

本系统是学习演示项目，没有密码加密、JWT、接口权限和生产数据安全设计。
