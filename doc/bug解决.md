# Android 拨号页面问题分析与解决方案

## 1. 修复范围

本次只修改本地模拟拨号应用，不接入 SIM 卡或系统真实拨号能力。修复号码显示、通话记录、时序设置、彩铃延迟及连续发起多次模拟通话的问题。

## 2. 问题分析与解决方案

### 2.1 输入 1 位号码时显示“未知”，3 位和 7 位展示层级不正确

原因：`NumberAttribution.displayText` 在没有匹配结果时强制回退为“未知地区”，因此刚输入 `1` 就出现错误提示。虽然归属地仓库已有三位运营商和七位号段匹配，但展示层没有按号码长度控制。

解决方案：

- 少于 3 位：归属信息留空，不显示“未知”。
- 3～6 位：只根据前三位显示运营商，例如 `159` 显示“移动”。
- 7 位及以上：优先最长七位号段，显示“省市 + 运营商”，例如 `1595503` 显示“安徽滁州 移动”。
- 七位号段表没有记录时降级为只显示运营商，不伪造归属地。

修改文件：

- `model/CallModels.kt`
- `data/NumberAttributionRepository.kt`

### 2.2 通话记录打不开、号码不能复拨、主页出现“已挂断”等结果文案

原因：通话记录行仅给录音图标绑定了点击事件，记录本身和号码没有交互；列表副标题还直接拼接了 `LOCAL_HANGUP` 等结果标签，导致主页出现“已挂断”。无录音记录也显示添加/录音相关图标，层级不清晰。

解决方案：

- 点击一整条记录进入“通话记录详情”。
- 点击记录中的号码或详情页“再次拨打”立即发起本地模拟复拨。
- 主页记录副标题只保留 HD、归属地和运营商，不再显示“已挂断/通话结束”。
- 只有存在录音的记录才在列表内显示绿色录音标记和时长。
- 外部录音的“插入/更换”和播放入口集中到记录详情页；列表右侧统一为详情入口。

修改文件：

- `MainActivity.kt`

### 2.3 没有接通和对方挂断时长设置

原因：服务中把接通等待固定为 3 秒、对方挂断固定为接通后 6 秒，DataStore 和设置页均没有对应配置。

解决方案：

- 隐藏设置页新增“通话时序”。
- “自动接通等待”支持 2～30 秒，默认 3 秒。
- “对方自动挂断”支持 1～120 秒，默认 6 秒，只用于“接通后对方挂断”模拟结果。
- 配置写入 DataStore；每次新通话开始时由 `CallSessionService` 读取，通话中途修改不影响当前会话。

修改文件：

- `data/SettingsRepository.kt`
- `service/CallSessionService.kt`
- `MainActivity.kt`

### 2.4 彩铃在拨出后立即播放

原因：原服务进入 `DIALING` 后马上启动彩铃音频，界面也立即加载彩铃视频。

解决方案：

- 增加 `ringbackActive` 会话状态。
- 拨出后的前 2 秒保持普通通话背景；满 2 秒且仍处于拨号中才启动彩铃音频/视频。
- 接通、挂断、忙线、无法接通或新会话开始时取消旧彩铃任务，避免跨会话播放。
- 自动接通等待的最小值限制为 2 秒，确保时序不会早于彩铃启动点。

修改文件：

- `model/CallModels.kt`
- `service/CallSessionService.kt`
- `MainActivity.kt`

### 2.5 返回主页后再次拨号无响应

原因：上一通电话的结束协程在短暂停留后会无条件把全局会话重置为 `IDLE` 并停止服务。如果用户在这个时间窗内开始下一通电话，旧协程可能覆盖新会话并停止承载新会话的服务，所以只能通过退出应用恢复。

解决方案：

- 每次结束流程保存自己的 `sessionId`、记录快照和服务 `startId`。
- 写入历史后、重置界面前都校验当前 `sessionId`；若新会话已经开始，旧结束任务只保存旧记录，不再修改新会话。
- 使用 `stopSelfResult(startId)`，存在更新的服务命令时不停止服务。
- 新会话开始时主动取消上一会话的拨号转换、彩铃和计时任务，并重新初始化媒体与计时字段。

修改文件：

- `service/CallSessionService.kt`

## 3. 修改后的关键交互

1. 输入 `1`：号码下方无“未知”文案。
2. 输入有效三位号段：显示运营商。
3. 输入内置七位号段：显示省市和运营商。
4. 挂断后进入电话记录：首页不展示“已挂断”，有录音的记录才显示录音标记。
5. 点击记录进入详情；点击号码或“再次拨打”可直接复拨。
6. 设置页可调整接通等待和对方挂断时长。
7. 发起通话 2 秒后才出现/播放彩铃；提前结束时彩铃不启动。
8. 上一通结束后无需退出应用即可继续发起下一通通话。

## 4. 验收建议

- 分别输入 `1`、`159`、`1595503`，检查空白、运营商、归属地加运营商三种展示。
- 完成一通无录音通话和一通有录音通话，确认只有后者出现录音标记。
- 从记录列表点击整行进入详情，再从号码和“再次拨打”两个入口测试复拨。
- 将自动接通设为 5 秒、对方自动挂断设为 10 秒，选择“接通后对方挂断”，用秒表核对两个阶段。
- 连续执行“拨号 → 挂断 → 返回主页 → 立即再次拨号”至少 5 次，确认新会话不会被旧结束任务重置。
- 本次不要求生成或安装 APK；代码级检查不等同于真机交互验收。
