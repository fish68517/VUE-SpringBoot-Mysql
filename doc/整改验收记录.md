# 在线投稿系统整改验收记录

整改日期：2026-05-01

## 一、已完成整改

1. 统一接口路径：取消后端 `server.servlet.context-path=/api`，所有业务接口统一通过 `/api/...` 访问，解决 `/api/api` 路径混乱问题。
2. 修复认证接口：登录、注册、退出、当前用户接口统一调整为 `/api/auth/...`。
3. 修复用户审批流程：注册用户默认进入 `PENDING` 状态，未审核用户不能登录；管理员审批通过后用户状态变为 `ACTIVE`。
4. 增加默认管理员：数据库脚本新增默认管理员账号 `admin / 123456`，状态为 `ACTIVE`。
5. 修复审稿分配流程：编辑只能给 `UNDER_REVIEW` 稿件分配审稿人，分配审稿人页面改为读取已通过初审的稿件。
6. 补齐终审流程：编辑端新增终审入口，可将稿件设置为 `ACCEPTED`、`REJECTED`、`REVISION_REQUIRED`。
7. 修复退修重投：作者可以编辑 `REVISION_REQUIRED` 稿件，提交修改稿后状态回到 `SUBMITTED`。
8. 修复编辑沟通：补齐 `editorService.getAllAuthors()`，作者列表使用 `/api/users/by-role/AUTHOR`。
9. 统一审稿人页面请求：去除 `/api/api` 硬编码和原生 axios 请求，统一使用封装后的 `api`。
10. 修复文件保存策略：上传文件保存到 Spring Boot 项目根目录 `image` 文件夹，数据库只保存文件名，删除时自动从 `image` 目录删除。
11. 修复数据库外键：资源 SQL 和交付 SQL 中主要业务外键改为 `ON DELETE CASCADE`。
12. 清理主要调试输出：移除后端关键流程中的 `System.out.println` 调试输出。

## 二、验收流程建议

1. 使用默认管理员 `admin / 123456` 登录后台。
2. 注册作者、编辑、审稿人账号。
3. 管理员在用户审核中批准注册账号。
4. 作者登录后提交稿件。
5. 编辑登录后初审通过稿件。
6. 编辑在“分配审稿人”中给该稿件分配审稿人。
7. 审稿人接受任务，查看稿件并提交审稿意见和评分。
8. 编辑在“审稿进度跟踪”中查看意见并提交终审结果。
9. 若终审为退修，作者上传修改稿后重新进入待初审。
10. 若终审为录用，编辑可进入稿件编辑页面进行校对并生成录用通知。

## 五、注意事项

1. 现有数据库如果已经创建过旧外键，需要重新导入更新后的 SQL，或手动删除旧外键后重建为 `ON DELETE CASCADE`。
2. 前端生产环境请求同源 `/api/...`，开发环境请求 `http://localhost:8080/api/...`。
3. 上传文件通过 `http://localhost:8080/image/文件名` 访问。
