# 汽车充电桩平台接口说明

## 1. 公共约定

- 后端地址：`http://localhost:8080`
- 接口前缀：`/api`
- Content-Type：`application/json`
- 不使用 JWT、Cookie Session 和权限校验。

成功返回：

```json
{"code":200,"message":"success","data":{}}
```

业务失败仍返回 HTTP 200，通过 `code` 和 `message` 判断。例如：

```json
{"code":400,"message":"该站点下存在充电桩，请先处理充电桩","data":null}
```

## 2. 前台接口

| 方法 | 地址 | 说明 |
| --- | --- | --- |
| POST | `/api/auth/login` | 明文密码登录 |
| POST | `/api/auth/register` | 普通用户注册 |
| GET | `/api/home/overview` | 首页指标 |
| GET | `/api/home/recommendations` | 推荐站点 |
| GET | `/api/regions/tree` | 区域树 |
| GET | `/api/stations` | 站点分页和筛选 |
| GET | `/api/stations/{id}` | 站点详情 |
| GET | `/api/stations/{id}/piles` | 站点充电桩状态 |
| GET | `/api/stations/{id}/guide` | 站内导览点 |
| GET | `/api/statistics/regions` | 区域排行 |
| GET | `/api/statistics/trend` | 日期趋势 |
| GET/POST/DELETE | `/api/favorites` | 收藏管理 |
| GET/POST | `/api/feedback` | 用户反馈 |
| GET/PUT | `/api/users/{id}` | 个人资料 |
| GET | `/api/notices` | 已发布公告 |

## 3. 后台通用 CRUD

后台模块统一使用以下接口：

| 方法 | 地址 | 说明 |
| --- | --- | --- |
| GET | `/api/admin/{module}` | 分页查询，参数 `pageNum/pageSize/keyword` |
| GET | `/api/admin/{module}/{id}` | 查询单条 |
| POST | `/api/admin/{module}` | 新增 |
| PUT | `/api/admin/{module}/{id}` | 修改 |
| DELETE | `/api/admin/{module}/{id}` | 删除 |

支持的 `{module}`：

```text
users
regions
stations
piles
status
usage-records
statistics
guide-points
notices
feedback
```

分页返回：

```json
{
  "code": 200,
  "message": "success",
  "data": {
    "records": [],
    "total": 0,
    "pageNum": 1,
    "pageSize": 10
  }
}
```

站点新增示例：

```json
{
  "regionId": 4,
  "stationCode": "WZ-DEMO-001",
  "stationName": "演示充电站",
  "address": "温州市鹿城区会展路",
  "longitude": 120.699361,
  "latitude": 27.994267,
  "stationType": 0,
  "openTime": "00:00-24:00",
  "operatorName": "演示运营商",
  "status": 1
}
```

## 4. 工作台和模拟接口

| 方法 | 地址 | 说明 |
| --- | --- | --- |
| GET | `/api/admin/dashboard` | 首页指标、今日记录、待处理反馈和服务时间 |
| GET | `/api/admin/modules` | 查询后台模块名 |
| POST | `/api/admin/simulation/run` | 手动执行一次状态和使用记录模拟 |
| POST | `/api/admin/statistics/regenerate?statDate=2026-08-10` | 重新生成某日区域统计 |

模拟任务故障概率约 3%，离线概率约 2%；早晚高峰的使用中概率高于普通时段。默认不自动执行，避免演示页面数字自行跳动。
