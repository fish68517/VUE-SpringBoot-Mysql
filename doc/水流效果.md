# 防汛预警系统动态水流效果修改方案

## 1. 架构分析与文件定位

本项目是 Vue 3 + TypeScript + Webpack 5 的组件库工程，防汛预警弹窗的调用链如下：

```text
BzWaterKpiDia/index.vue
  └─ 根据 OPEN_WATER_KPI_DIA / OPEN_DIA 事件选择 water-prediction
      └─ WaterlogPredictionDia.vue
          ├─ flood-data.ts：站点、嘉陵江/长江轨迹和颜色
          ├─ flood-engine.ts：本地预警规则计算
          ├─ Leaflet：河道、站点、标签和预警路径
          └─ Canvas + CSS：动态水流视觉层
```

因此，例图中左侧地图和河道的实际实现文件就是：

`src/package/BZAQ/BzWaterKpiDia/components/WaterlogPredictionDia.vue`

`BzWaterKpiDia/index.vue` 只负责弹窗路由和事件接入，不适合承载地图动画。河道坐标继续复用 `flood-data.ts` 中的 `RIVERS.jialing` 和 `RIVERS.yangtze`，不重复维护数据。

## 2. 原画面问题

例图中的左侧区域存在两个主要问题：

1. 河道只有三条普通 Leaflet 折线，视觉上较细、层次较少，动态效果仅是一条简单虚线。
2. 弹窗会从较小的 playground 容器向外溢出，Leaflet 可能在容器尺寸尚未稳定时执行 `fitBounds`，导致河网缩在右下区域，左侧出现大面积空白。

## 3. 已实施的效果方案

### 3.1 五层河道结构

每条河道由同一份轨迹生成五层 SVG 折线：

1. `river-glow`：宽范围低透明度呼吸光晕。
2. `river-bank`：半透明水体外沿，增强河道体积感。
3. `river-body`：嘉陵江蓝色、长江橙色的主水体。
4. `river-current`：长短交替的高亮流带，通过 `stroke-dashoffset` 持续推进。
5. `river-spark`：高亮点状水花，以不同速度沿河道移动。

嘉陵江与长江使用不同的动画周期，避免两条河流机械同步。

### 3.2 Canvas 粒子水流

在 Leaflet 图层上方增加透明 Canvas：

- 46 个粒子按固定比例分布到两条河道；
- 根据 Leaflet 当前投影，把经纬度轨迹转换为屏幕坐标；
- 粒子沿分段累计长度插值移动，而不是沿直线穿越拐点；
- 每个粒子带发光拖尾，采用 `lighter` 混合形成水面亮斑；
- 朝天门汇流点增加扩散圆环，突出两江交汇位置；
- 绘制帧率约 30 FPS，设备像素比最高取 1.5，控制大屏渲染成本。

该动画只读取本地 `RIVERS` 数据，不依赖图片、视频、第三方动画库或后端接口。

### 3.3 科技感环境层

左侧地图补充了以下静态/轻量动态装饰：

- 48px 半透明网格；
- 多层深蓝径向渐变背景；
- “水势动态推演 / 两江汇流态势”信息牌；
- 左下角 FLOWING 动态状态条；
- 站点呼吸光效；
- 与现有图例、站点标签和预警路径保持分层，不阻挡地图操作。

### 3.4 地图尺寸与视野修复

新增 `ResizeObserver` 监听地图容器：

- 容器变化后执行 `map.invalidateSize()`；
- 重新按全部站点执行 `fitBounds()`；
- 同步刷新 Canvas 尺寸和投影轨迹；
- 初始化后连续两帧校正，解决河网挤在右下角的问题。

弹窗尺寸改为：

```css
width: min(1700px, calc(100vw - 16px));
height: min(1000px, calc(100vh - 16px));
```

这样保留 1700 × 1000 的设计稿上限，同时在较小屏幕中不会整体跑出视口。

### 3.5 纯本地静态运行

本次将此页面的演示逻辑改为纯本地实现：

- 站点和河道来自 `flood-data.ts`；
- 预警计算使用现有 `flood-engine.ts`；
- 移除了站点列表和洪峰模拟的 Axios 请求；
- Leaflet 必需样式以内嵌最小样式提供，不再请求 unpkg CDN；
- “重置”恢复本地静态站点和输入状态，不会等待远程服务。

草街放水量、降雨量输入保留为界面字段；当前本地预警规则仍以站点水位为主要计算依据。

### 3.6 动效降级与资源清理

- 支持 `prefers-reduced-motion`，用户关闭动态效果时停用 CSS 动画并隐藏粒子 Canvas；
- 组件卸载时取消 `requestAnimationFrame`、定时器和 `ResizeObserver`；
- 地图移动、缩放、重建后重新计算粒子轨迹，避免粒子与河道错位。

## 7. 后续可调参数

视觉强度可直接在 `WaterlogPredictionDia.vue` 中调整：

- 粒子数量：`flowParticles` 的 `length: 46`；
- 粒子速度：`speed: 18 + ...`；
- Canvas 刷新间隔：`timestamp - lastFlowFrame < 32`；
- 河道宽度：`addRiverLayers()` 中五层折线的 `weight`；
- 流带速度：`.river-current`、`.river-spark` 的 `animation-duration`；
- 背景网格：`.water-grid` 的 `background-size: 48px 48px`。
