# Android 拨号页面一比一复刻开发方案

## 1. 方案结论

本项目使用 **Kotlin + Jetpack Compose** 实现纯本地的 Android 拨号界面复刻。应用不接入 SIM 卡、系统通讯录、系统通话记录、短信或真实拨号能力，也不申请 `CALL_PHONE`、`READ_CONTACTS`、`READ_CALL_LOG` 等权限。第二阶段根据 `doc/需求.txt` 增加真实的本地麦克风录音、录音播放/导入、离线号码归属地、模拟通话状态、后台计时、前台服务通知、画中画和可配置媒体，因此会新增必要的录音、通知和前台服务权限，但仍不是系统电话应用。

视频中实际出现了三个应用状态，复刻范围应覆盖：

1. 拨号键盘页：逐位输入号码、显示归属地、删除号码。
2. 模拟呼叫页：模糊背景、号码与状态、九宫格通话按钮。
3. 电话记录页叠加拨号面板：用于模拟挂断后的返回效果。
4. 隐藏设置页：导入背景图、彩铃视频、铃声、彩铃和各通话结果语音条。
5. 画中画/后台状态：离开主页面后继续计时和录音，通过常驻通知显示电话图标及当前状态。

顶部“录屏计时胶囊”、状态栏网络/电量图标和底部系统导航键属于手机系统层，不是拨号应用自身 UI。应用只预留安全区并设置状态栏、导航栏颜色，不把录屏控制条画进业务页面。

## 2. 视频分析依据

源文件：`doc/拨号视频.mp4`

| 项目 | 分析结果 |
| --- | --- |
| 视频尺寸 | 576 × 1280 px，纵向 9:20 |
| 时长 | 16.521 秒 |
| 视频编码 | H.264 |
| 帧数 | 450 帧，变帧率，平均约 27.34 fps |
| 0.00–11.46 秒 | 拨号键盘页，依次输入 `159 5503 9377` |
| 11.46–14.09 秒 | 模拟“正在拨号”页面 |
| 14.09–16.52 秒 | 电话记录页与底部拨号面板 |

视频画面很可能由 1080 × 2400 的 20:9 手机录屏转码为 576 × 1280。实现时以 **360 × 800 dp** 为设计基准，换算关系为：

```text
视频坐标 px × 0.625 ≈ Android 设计坐标 dp
Android 设计坐标 dp × 1.6 ≈ 视频坐标 px
```

该换算只用于首轮布局。最终必须用目标设备截图与视频帧叠加校准，因为视频压缩、系统字体和实际屏幕密度都会带来 1–3 px 的误差。

## 3. 页面视觉规格

### 3.1 全局基准

| 属性 | 建议值 | 说明 |
| --- | --- | --- |
| 设计画布 | 360 × 800 dp | 对应视频 576 × 1280 px |
| 页面背景 | `#FFFFFF` | 视频中主体为纯白或接近纯白 |
| 主文字 | `#1A1A1A` | 数字、标题、主操作文字 |
| 次文字 | `#929292` | 字母、归属地、次级说明 |
| 禁用文字/图标 | `#C9C9C9` | 联系人、收藏及不可用按钮 |
| 品牌绿色 | `#14C150` | 从视频高饱和像素采样得到，主采样 RGB 为 20/193/80 |
| 挂断红色 | `#EC3B35` | 从呼叫页主按钮采样得到，主采样 RGB 为 236/59/53 |
| 分隔线 | `#E8E8E8` | 电话记录列表 |
| 字体 | `sans-serif` / `sans-serif-medium` | 优先跟随目标手机系统字体；不得用默认衬线字体 |
| 图标风格 | 2 dp 左右圆角线性图标 | 不能混用不同线宽的图标库 |

字体大小均以 `sp` 设置，但页面布局不能受系统“超大字体”破坏。用于一比一演示的构建应固定应用内字体缩放系数为 1.0，并在文档中注明这是视觉演示模式。

| 号码文本中心 | x = 180 dp，y 约 106 dp |
| 号码区最大宽度 | 320 dp，单行居中 |
| 归属地文本 | 号码下方 6–8 dp |
| 拨号面板顶部 | y 约 313 dp |
| 面板上圆角 | 20–22 dp |
| 面板阴影 | 向上扩散 18–24 dp，黑色 5%–8% |
| 顶部四项操作中心 x | 45 / 135 / 225 / 315 dp |
| 数字三列中心 x | 72 / 180 / 288 dp |
| 数字四行中心 y | 416 / 474 / 531 / 589 dp |
| 下方功能行中心 y | 655 dp |

#### 字号与字重

| 内容 | 字号 | 字重/颜色 |
| --- | --- | --- |
| 顶部已输入号码 | 30–32 sp | Medium，`#1A1A1A` |
| 归属地“安徽滁州 移动” | 13–14 sp | Regular，`#777777` |
| 数字键主数字 | 27–29 sp | Medium，`#1A1A1A` |
| 数字下方字母 | 9–10 sp | Medium，字距约 0.22 em，`#929292` |
| 四项快捷操作标签 | 9–10 sp | Regular，`#666666` |
| 底部导航标签 | 10–11 sp | Regular |
| 呼叫按钮“HD” | 9 sp | Bold，白色 |

号码格式化规则只用于显示：

```text
1–3 位：159
4–7 位：159 5503
8–11 位：159 5503 9377
```

内部仍保存未加空格的纯数字字符串。数字不足时，号码区保持原位置，不因文字宽度变化产生垂直跳动。

#### 可见内容

- 快捷操作：`新建联系人`、`保存至已有联系人`、`视频呼叫`、`发送信息`。
- 数字键：`1–9`、`*`、`0`、`#`。
- 字母：`ABC`、`DEF`、`GHI`、`JKL`、`MNO`、`PQRS`、`TUV`、`WXYZ`。
- `1` 下方使用视频中的语音信箱样式小符号；`*` 下方为 `(P)`；`0` 下方为 `+`；`#` 下方为 `(W)`。
- 功能行：左侧九点拨号盘图标，中间绿色呼叫按钮，右侧退格图标。
- 底部导航：`电话`、`联系人`、`个人收藏`，仅“电话”为绿色选中态。

### 3.3 模拟呼叫页

该页面仅做视觉演示，不创建系统通话，不启动 `ACTION_CALL` 或 `ACTION_DIAL`。

| 元素 | 建议规格 |
| --- | --- |
| 背景 | 棕黑、暖灰、浅粉灰组成的抽象位图或多层径向渐变 |
| 背景处理 | 24–30 dp 高斯模糊，并叠加约 22%–30% 黑色蒙层 |
| 背景取样参考 | `#221C17`、`#483D36`、`#573B2E`、`#998F83`、`#EEE2E7` |
| 号码 | `159 5503 9377`，30–32 sp，Medium，白色 |
| 归属地 | 13–14 sp，白色约 72% 不透明度 |
| 状态 | `正在拨号。`，13–14 sp，白色约 72% 不透明度 |
| 六个功能圆 | 68 × 68 dp，白色约 16%–25% 不透明度 |
| 挂断按钮 | 68 × 68 dp，`#EC3B35` |
| 底部三按钮 | 拨号盘 / 挂断 / 扬声器，三列等距 |

按钮文字依次为：

```text
录音       AI 接听       添加通话
视频通话   静音          更多
```

录音、添加通话、视频通话和静音在视频中带有不同程度的禁用灰度；`AI 接听` 和 `更多` 更清晰。复刻时应分别设置透明度，不能把六个按钮做成完全相同的状态。

### 3.4 电话记录页叠加拨号面板

- 顶部标题为 `电话`，约 28–30 sp，Bold。
- 右上角为竖向三点菜单。
- 列表头像约 40 dp，使用蓝灰渐变圆形占位头像。
- 主文字 16–17 sp，次文字 10–12 sp。
- 右侧显示 `刚刚`、`06:42`、`昨天` 和信息图标。
- 列表中的示例记录必须写在本地假数据中，不读取系统通话记录。
- 拨号面板从页面下半部覆盖列表，顶部约 y = 376 dp，使用 20–22 dp 上圆角和向上阴影。
- 该状态复用同一套 `DialPad` 组件，只改变面板的垂直位置，避免两份键盘出现尺寸偏差。

## 4. 交互与状态机

以下是第一阶段已经建立的基础交互；第二阶段将在不改变页面入口的前提下，用第 13 节的完整会话状态机替换这里的简化转换：

```text
DialPad
  ├─ 点击数字：追加数字并刷新格式化号码/归属地
  ├─ 点击退格：删除一位；长按可清空
  └─ 点击绿色按钮：进入 Calling，仅更新本地 Compose 状态

Calling
  ├─ 点击功能按钮：只切换图标高亮，不调用系统服务
  └─ 点击红色挂断：进入 CallHistory，并新增一条本地临时记录

CallHistory
  └─ 点击拨号盘区域：显示或保持底部 DialPad 面板
```

第二阶段需要持久保存通话记录、录音及媒体配置，因此使用 Room 和 DataStore 做本地持久化；不需要后端、云数据库或账号体系。应用卸载后本地数据可以一并清除，用户通过系统文件选择器导入的媒体只保存持久 URI 授权和元数据。

## 6. 实施步骤

1. 创建最小 Android 项目，单 Activity、Compose、最低版本建议 API 26。
2. 设置 360 × 800 dp 基线与 edge-to-edge，统一状态栏/导航栏策略。
3. 从视频关键帧建立坐标标注表，完成颜色取样和图标轮廓清单。
4. 先实现可复用 `DialPad`，再实现号码区、快捷操作区和底部导航。
5. 加入纯本地号码格式化、删除和页面状态切换。
6. 实现模拟呼叫页的模糊背景、按钮透明度和挂断返回。
7. 实现电话记录假数据及拨号面板覆盖状态。
8. 在目标设备或同尺寸模拟器截图，逐区域做像素对比并修正坐标、字号、字重、字距和图标线宽。
9. 执行静态检查和 Debug 构建，确认 Manifest 中没有拨号及通讯录权限。
10. 在保留现有页面效果的前提下拆分 `MainActivity.kt`，引入会话状态机、前台服务和本地仓库。
11. 加入离线号码归属地、真实录音、记录播放与外部录音导入。
12. 加入画中画、后台计时、通话通知、隐藏媒体设置和语音条配置。
13. 完成前后台、权限拒绝、进程恢复、媒体失效和多种通话结果的专项测试。

## 7. 一比一验收方法

建议固定同一台设备、同一显示缩放、同一字体缩放进行验收：

```powershell
adb exec-out screencap -p > dialer-current.png
```

将截图缩放到 576 × 1280 后，与对应视频帧做 50% 透明度叠加和差分图。验收标准：

- 排除系统状态栏、录屏胶囊、底部系统导航键后，主要组件位置误差不超过视频坐标 2 px。
- 绿色、红色和主文字等关键色的 RGB 单通道误差不超过 5；渐变/阴影按区域平均值比较。
- 文字基线误差不超过 2 px，字号、字重和字距肉眼不可见明显差异。
- 绿色呼叫按钮视频帧中约为 87 × 87 px，实现目标约为 54 × 54 dp。
- 呼叫页红色挂断按钮视频帧中约为 110 × 110 px，实现目标约为 68 × 68 dp。
- 数字输入、退格、进入模拟呼叫和挂断返回均只改变本地 UI，不触发系统拨号器或权限弹窗。
- 清单检查确认没有 `CALL_PHONE`、`READ_CALL_LOG`、`WRITE_CALL_LOG`、`READ_CONTACTS` 权限；录音、通知和前台服务权限只在对应功能启用时申请或声明。

## 8. 风险与边界

1. 视频经过压缩，抗锯齿边缘和阴影颜色不能直接视为原始设计值，必须通过截图差分迭代。
2. OEM 系统字体会影响中文宽度和数字字形。若要求不同设备也完全一致，需要随应用打包经过授权的字体文件；否则应以录屏来源手机作为验收设备。
3. 录屏胶囊、信号、电量和系统导航键无法由普通应用可靠控制，也不应伪造成业务 UI；验收时应遮罩这些区域。
4. 呼叫页背景是高度模糊的图像。建议制作独立本地背景素材并固定裁切方式，避免运行时随机渐变导致截图不稳定。
5. 本方案中的字号和坐标是依据 576 × 1280 视频首轮反推值。实现完成后的截图校准是“一比一”交付不可省略的环节。
6. 手机号归属地不是仅靠前三位即可准确计算，必须使用可更新的号段数据表；未知或数据不完整时要明确显示“未知地区/运营商”，不能伪造结果。
7. Android 不允许应用在后台任意读取剪贴板，因此“复制号码后自动显示”限定为应用重新获得前台焦点时读取并提示填入。
8. 后台麦克风录音和状态栏电话图标依赖前台服务及常驻通知；用户拒绝录音或通知权限时必须降级为仅计时模拟。
9. 外部媒体可能被移动、删除或撤销 URI 授权，播放前必须验证可读性并回退到默认资源。

## 9. 交付物定义

最终代码交付应包含：

- 可直接在 Android Studio 打开的完整工程。
- 三个页面状态及本地演示交互。
- 本地图标和呼叫页背景素材。
- 不含真实拨号、系统通讯录、系统通话记录权限的 Manifest；仅包含录音、通知、前台服务等新增功能所需权限。
- 本地通话记录、录音文件、录音导入与播放能力。
- 背景图、铃声、彩铃视频和通话结果语音条的隐藏设置页。
- 后台计时、前台服务通知和画中画演示能力。
- 三个原始基准状态及第二阶段新增状态的验收截图、差分图和功能录屏。
- Debug APK（如后续明确要求构建）。

## 10. 第二阶段需求范围与实现决策

本节对应 `doc/需求.txt`。第二阶段必须在当前已能运行的 Compose 工程上增量开发，保留现有拨号页的颜色、字号、坐标和基本交互，不推倒重做。

| 新需求 | 实现方案 | 明确边界 |
| --- | --- | --- |
| 号码归属地自动产生 | 内置离线号段表，按最长前缀匹配省、市、运营商 | 无匹配时显示未知，不联网猜测 |
| 支持 `190/195/192/165` 特殊号段 | 在号段表中设置专门规则和运营商兜底 | 省市仍以完整七位号段数据为准 |
| 点击录音后同步秒数并真实录音 | `CallSessionService` 统一计时，`MediaRecorder` 录制 AAC/M4A | 不录制真实通话线路声音，只录设备麦克风可采集内容 |
| 通话记录带录音、可播放 | Room 记录录音关联，Media3 播放 | 播放失败时显示文件失效状态 |
| 可插入外部录音 | SAF `OpenDocument` 导入并保存持久 URI | 不申请整盘存储权限 |
| 铃声、彩铃隐藏设置 | 标题长按或右上角菜单进入隐藏设置页 | 设置入口隐蔽但可重复进入 |
| 对方/自己挂断表现不同 | 独立事件和状态转换 | 都是本地模拟，不监听真实运营商事件 |
| 接通后图标变亮 | 按通话状态驱动按钮可用性和透明度 | 拨号中与接通中不能复用一套静态颜色 |
| 缩小/后台继续计时录音 | 前台服务 + 画中画 + 单调时钟 | 不申请悬浮窗权限 |
| 状态栏电话图标 | Ongoing Notification 的小图标 | Android 状态栏实际展示由系统主题控制 |
| 从其他应用复制号码后自动显示 | 在 `onResume` 读取剪贴板，识别号码后提示/自动填充 | 不在后台持续监听剪贴板 |
| 背景图和彩铃视频自动设置 | 默认媒体配置 + 按号码/状态选择策略 | 用户导入资源优先，失效后回退默认资源 |
| 设置“通话中/无法接通/用户正忙”等语音条 | 状态到本地音频 URI 的映射设置 | 不产生真实运营商网络状态 |

## 11. 总体技术架构

### 11.1 增量改造原则

当前工程主要逻辑集中在 `MainActivity.kt`。第二阶段先提取状态和组件，再增加服务及数据层：

```text
Compose UI
  ├─ DialerViewModel：输入号码、页面状态、归属地、设置
  ├─ CallSessionViewModel：观察服务提供的会话快照
  └─ SettingsViewModel：媒体导入及结果语音配置
          │
          ▼
CallSessionService（前台服务，唯一会话计时源）
  ├─ CallStateMachine
  ├─ CallRecorder
  ├─ LocalMediaPlayer
  └─ NotificationController
          │
          ▼
Room + DataStore + 应用私有媒体目录/SAF URI
```

UI 不自行累加秒数。前台页面、画中画、通知和录音记录全部读取同一个会话快照，避免切后台后多个计时器漂移。

### 11.2 时间基准

- 使用 `SystemClock.elapsedRealtime()` 保存拨号开始、接通和录音开始时刻。
- 展示秒数通过“当前单调时钟减开始时刻”计算，不依赖 `delay(1000)` 的累计次数。
- 进程短暂重建时从持久化的时间戳恢复；设备重启后未完成的会话标记为“异常中断”，不能继续伪造运行。
- 通话时长从 `CONNECTED` 时刻开始；录音时长从用户点击录音且录音器真正启动成功后开始，两者分别保存。

## 12. 号码归属地自动识别计划

### 12.1 数据格式

新增 `assets/number_prefixes.json`：

```json
{
  "version": 1,
  "updated_at": "YYYY-MM-DD",
  "records": [
    {
      "prefix": "1595503",
      "province": "安徽",
      "city": "滁州",
      "operator": "中国移动",
      "number_type": "mobile"
    }
  ],
  "special_prefixes": {
    "190": "可配置运营商名称",
    "195": "可配置运营商名称",
    "192": "可配置运营商名称",
    "165": "可配置运营商名称"
  }
}
```

运营商名称以实际导入的数据源为准，不在代码中凭经验写死。数据加载后构造成前缀索引，拨号时最长匹配，避免每次按键都遍历完整 JSON。

### 12.2 匹配顺序

1. 去除空格、短横线、括号和 `+86`，保留规范号码。
2. 对普通手机号优先匹配前七位归属地记录。
3. 未命中七位时匹配三位特殊号段规则，包括 `190`、`195`、`192`、`165`。
4. 固话可按区号匹配；短号、服务号和非法号码显示对应类型，不显示虚假城市。
5. 返回结构化结果：`province/city/operator/numberType/confidence`。

### 12.3 UI 表现

- 输入前三位后可先显示运营商；达到七位后更新省市。
- 结果示例：`安徽滁州 移动`。
- 未知结果：`未知地区` 或只显示已确认的运营商。
- 输入、粘贴和历史记录回填使用同一识别逻辑。

## 13. 通话会话、挂断与图标状态

### 13.1 状态机

```text
IDLE
  └─ 点击呼叫 → DIALING
       ├─ 模拟接通 → CONNECTED
       ├─ 模拟无人接听 → UNREACHABLE → ENDED
       ├─ 模拟用户正忙 → BUSY → ENDED
       └─ 自己挂断 → SELF_HANGING_UP → ENDED

CONNECTED
  ├─ 对方挂断 → REMOTE_ENDED → ENDED
  ├─ 自己挂断 → SELF_HANGING_UP → ENDED
  └─ 后台/画中画 → 状态不变

ENDED → 写入通话记录 → CALL_HISTORY
```

### 13.2 文案与延时

| 事件 | 页面文案 | 建议停留时间 | 记录结果 |
| --- | --- | --- | --- |
| 自己点击挂断 | `正在挂断…` | 600–900 ms | `LOCAL_HANGUP` |
| 对方挂断 | `通话结束` | 1.0–1.5 s | `REMOTE_HANGUP` |
| 无法接通 | `无法接通` | 播放完语音条后 600 ms | `UNREACHABLE` |
| 用户正忙 | `用户正忙` | 播放完语音条后 600 ms | `BUSY` |
| 正常接通 | `通话中 00:00` | 直到挂断 | `CONNECTED` |

延时由协程 Job 管理；离开页面或状态改变必须取消旧 Job，防止重复跳转和重复写记录。

### 13.3 图标明暗矩阵

| 功能 | 拨号中 | 已接通 | 无录音权限 | 选中态 |
| --- | --- | --- | --- | --- |
| 录音 | 灰色不可用 | 高亮可点 | 灰色并提示授权 | 绿色/白色实心强调 |
| 静音 | 灰色或低亮 | 可点 | 可点 | 白色实心圆、深色图标 |
| 扬声器 | 可点 | 可点 | 可点 | 白色实心圆、深色图标 |
| 拨号盘 | 低亮 | 可点 | 可点 | 弹出数字键盘 |
| 添加通话/视频通话 | 保持演示禁用 | 仍禁用 | 不适用 | 不实现真实功能 |

## 14. 真实录音、同步计时和播放

### 14.1 录音生命周期

1. 仅在 `CONNECTED` 状态允许点击录音。
2. 首次点击请求 `RECORD_AUDIO`；拒绝后保持禁用并给出设置入口。
3. 权限允许后由前台服务启动 `MediaRecorder`，编码为 AAC，容器为 `.m4a`。
4. 文件写入 `files/recordings/<callId>-<startedAt>.m4a`，使用临时扩展名录制，成功停止后再标记为可播放。
5. UI 同时显示通话总时长和录音时长；二者从各自的单调时钟起点计算。
6. 挂断、异常、应用被移除任务或录音错误时统一调用安全停止，保证文件句柄释放。

### 14.2 通话记录录音标记

- 有可用录音的记录显示录音波形/麦克风标记和录音时长。
- 点击记录进入详情页，可播放、暂停、拖动进度、删除关联录音。
- 播放使用 Media3，确保应用内录音和外部导入音频共用播放器。
- 删除通话记录时默认不直接删除外部导入文件；应用自产录音需要二次确认后删除。

### 14.3 插入外部录音

- 在记录详情页提供“插入录音”。
- 使用 `ActivityResultContracts.OpenDocument`，MIME 类型为 `audio/*`。
- 调用 `takePersistableUriPermission` 保存读取授权。
- 保存显示名、URI、时长、MIME、来源类型和关联记录 ID。
- URI 不可读时显示“录音文件已失效”，允许重新选择，不导致详情页崩溃。

## 15. 后台、画中画与状态栏电话图标

### 15.1 前台服务

`CallSessionService` 在模拟通话开始时启动，负责：

- 维护当前会话状态和单调计时基准。
- 管理录音器和状态语音播放器。
- 创建 `IMPORTANCE_LOW` 的通话通知渠道。
- 发布 ongoing 通知，使用白色透明背景的小电话图标。
- 通知显示号码、归属地、当前状态和时长，并提供“返回通话”“挂断”操作。
- 会话结束后停止前台状态，但保留已写入的历史记录。

### 15.2 画中画

- Android 8.0 及以上使用 Picture-in-Picture，不申请 `SYSTEM_ALERT_WINDOW`。
- 用户按 Home 或点击“缩小”时进入画中画，显示号码、时长和挂断按钮。
- 画中画与完整页面订阅同一服务状态，不创建第二个计时器。
- Android 版本或设备不支持画中画时，退化为后台通知模式。

### 15.3 进程与异常恢复

- Activity 销毁不停止活动会话。
- 服务被系统回收时，通过最后会话快照恢复计时；若录音无法恢复则结束该录音段并标记“异常中断”。
- 用户从通知点击挂断时必须执行与页面挂断相同的状态机路径。

## 16. 剪贴板号码回填

- 仅在应用进入前台的 `onResume`/生命周期 `ON_RESUME` 时读取剪贴板。
- 支持纯数字、带空格、短横线、括号和 `+86` 的常见格式。
- 规范化后要求长度和格式合法，避免把验证码、订单号直接当电话号码。
- 与当前输入不同且识别为号码时，显示轻量提示“检测到复制的号码”，用户确认后填入；可在设置中启用“自动填入”。
- 同一个剪贴板内容通过哈希去重，避免每次返回应用都重复弹出。
- 不实现后台剪贴板监听，不申请无关权限。

## 17. 背景图、铃声、彩铃视频与语音条设置

### 17.1 隐藏设置入口

- 默认入口：电话记录页标题“电话”连续点击五次，或长按呼叫页号码 1.5 秒。
- 设置页退出后仍保持主页面一比一视觉，不在正常界面新增明显按钮。
- 设置页提供“恢复默认资源”，每项可以单独清除。

### 17.2 可配置资源

| 配置项 | 支持格式 | 用途 |
| --- | --- | --- |
| 通话背景图 | JPEG、PNG、WebP | 呼叫页全屏背景，中心裁切、模糊、加暗层 |
| 铃声 | MP3、M4A、WAV、OGG | 模拟来电或等待提示 |
| 彩铃音频 | MP3、M4A、WAV、OGG | 拨号/等待接通阶段循环播放 |
| 彩铃视频 | MP4/WebM（以设备解码能力为准） | 呼叫页背景循环静音/带音播放 |
| 状态语音条 | 常见音频格式 | 通话中、无法接通、用户正忙、通话结束等状态 |

媒体通过 SAF 导入并持久保存 URI。应用启动或播放前检查资源有效性；无资源、解码失败或权限失效时自动回退到内置默认背景和提示音。

### 17.3 自动选择策略

- 默认按当前通话状态选择媒体：拨号中播放彩铃，接通后停止彩铃并展示背景，结果状态播放对应语音条。
- 允许设置“全局默认”和“指定号码配置”；号码级配置优先于全局配置。
- 视频和音频不能重复抢占声音通道：彩铃视频带音时停用独立彩铃音频。
- 接通、挂断和切换状态时采用 150–300 ms 淡入淡出，避免爆音。

## 21. 第二阶段验收标准

### 21.1 功能验收

- 输入普通手机号和 `190/195/192/165` 号段时，能返回数据表中对应的运营商；有七位记录时返回省市。
- 接通后通话时长连续增长；前后台切换和画中画前后误差不超过 1 秒。
- 点击录音后真实生成可播放文件，录音时长与服务记录误差不超过 1 秒。
- 有录音的历史记录显示录音标记，可播放、暂停、拖动，能够插入外部录音。
- 自己挂断先显示“正在挂断…”，对方挂断显示“通话结束”，两者历史结果字段不同。
- 拨号中与接通中图标的可用性、亮度和选中态有明确差异。
- 退到后台后通知保持存在并显示电话图标、号码、状态和时长；从通知能返回页面或挂断。
- 支持画中画时，缩小后计时和录音不中断；不支持时正确退化为通知。
- 从其他应用复制合法号码并返回本应用后，能够提示或按设置自动填入主页。
- 隐藏设置能够导入并使用背景图、铃声、彩铃视频以及各结果语音条。
- 媒体文件失效、权限拒绝和录音异常不会导致崩溃，并有可理解的降级提示。

### 21.2 自动化测试重点

- `PhoneNumberNormalizerTest`：空格、`+86`、短横线、非法字符和长度边界。
- `NumberAttributionRepositoryTest`：七位最长匹配、四个特殊号段、未知号段。
- `CallStateMachineTest`：全部合法转换、非法事件忽略、延时任务取消。
- `CallClockTest`：前后台、暂停渲染、时钟跳动和恢复。
- `RecordingRepositoryTest`：成功录音、零字节文件、异常停止、外部 URI 失效。
- `ClipboardNumberDetectorTest`：电话号码与验证码/订单号区分、重复剪贴板去重。
- Compose UI 测试：图标明暗、结束文案、录音标记、隐藏设置入口和画中画按钮。

### 21.3 验收边界

- “拨号、接通、无法接通、用户正忙、对方挂断”均为本地状态模拟，不代表真实蜂窝网络结果。
- 麦克风录音不能保证捕获对方声音，也不能绕过 Android 对真实通话录音的限制。
- 状态栏图标由系统通知机制生成，其颜色、尺寸和位置由 Android/OEM 决定，不纳入应用像素级差分。
- 剪贴板自动识别仅在应用获得前台焦点时执行，这是 Android 平台隐私限制下的实现边界。
