# 第二阶段本地构建与交接说明

工程目录：`E:\bishe27\springboot-vue-mysql-android\郑州-城市智慧供水\code`。

本阶段只进行本地编码、构建和测试，没有上传 uniCloud、调用云打包或部署真实设备接口。后续上传由用户自行完成。

## 1. 本地环境与构建

沿用工程锁文件及 uni-app 5.24 对应依赖。入口是普通 uni-app `App.vue`、`main.ts`、`pages.json` 和 `manifest.json`，不是 uni-app x。依赖不需要独立升级。

在 `code` 目录执行：

```powershell
npm ci
npm run check
npm test
npm run build:h5
npm run release:check
npm run build:app
```

- H5 目录：`code/unpackage/dist/build/h5`。
- App-vue 资源目录：`code/unpackage/dist/build/app`。
- 测试、截图及样例文件：`code/unpackage/evidence/phase2`；原主流程回归输出在 `code/unpackage/evidence`。
- `build:app` 编译的是资源，**不会生成签名 APK**。

本地预览：`npm run preview`，地址 `http://127.0.0.1:4173`。不要直接通过文件协议打开 `index.html`。如 4173 已启动，不要重复启动同端口服务。

## 2. 用户自行上传 H5

1. 先运行检查、测试和 H5 构建，再执行发行资源检查。
2. 在自己的 uniCloud 空间选择前端网页托管，上传 `code/unpackage/dist/build/h5` **目录内的全部内容**，包括 `index.html`、`assets` 和 `static`。
3. 不上传整个工程、`doc`、测试证据、签名材料、原始需求文档或开发缓存。本地 JSON 已随客户端打包，不需要创建云数据库或云函数。
4. 当前 H5 使用 hash 路由和根路径 `/`。发布后打开首页登录，并直接刷新 `/#/pages/map/changes`、`/#/pages/video/index` 等路由检查资源是否完整。若部署在子目录，先调整 H5 base 再重新构建，不能只移动 HTML。
5. 验证两个在线视频通道能播放、离线通道显示占位、CSV/JSON 能下载、浏览器没有 404、刷新后本地业务状态保留。
6. 线上地址、访问情况和托管平台配置只有用户上传后才能确认，本次没有生成线上访问记录。

演示账号是客户端公开的虚构数据；这是纯前端演示工程，角色约束用于业务演示，不构成生产服务端鉴权。

## 3. Android 打包

1. 使用 HBuilderX 打开 `code`，保持 Vue 3 普通 uni-app 工程类型。
2. 在 `manifest.json` 中填写自己的 DCloud AppID、Android 包名和签名配置。当前 AppID 留空，未借用其他项目的标识或证书。
3. App 原生模块已声明 `VideoPlayer`。打包时确认包含视频模块，并将本地视频和 ECharts 资源一起打包。
4. 连接自己的 Android 设备，先使用运行基座验证地图 Canvas、图表 renderjs、视频、返回路径、后台暂停和文件操作，再生成正式签名 APK。
5. 如采用 HBuilderX 云打包，上传动作和签名授权由用户自己执行；本次未执行。也可按自己的离线打包环境处理，不应把 `unpackage/dist/build/app` 直接改名为 APK。
6. 安装后按下面的移动验收清单验证。无设备时不能把 H5 手机宽度截图视为 Android 已通过。

## 4. 复验命令和路径

在预览服务运行时执行：

```powershell
npm run test:browser
npm run test:phase2
npm run test:stability
```

第三条默认连续运行 30 分钟，比较页面反复切换后保留的堆、DOM、监听器和 Canvas 数量，同时记录大屏加载时间。它使用本机 Chrome、强制 GC 辅助比较保留资源，不能替代 Android 设备性能测量。短时诊断可设置 `STABILITY_MINUTES`，但不得将缩短的运行描述为 30 分钟验收。

自动测试使用独立浏览器上下文及本机模拟账号，不修改用户当前浏览器会话，不发送外部通知。

## 5. 用户上传后及真机复验清单

| 项目 | 操作 | 通过条件 |
| --- | --- | --- |
| 告警与维修 | 受理→接单→提交→管理员验收，重复两遍 | 告警关闭、工单完成、计数一致，重置后恢复 |
| 巡检 | 挂接模板→上报异常→改派→完成 | 必填校验有效，异常工单独立，任务统计一致 |
| 地图审核 | 修改点或线→驳回重提→逐级终审 | 前五级不改有效台账，第六级生效，刷新保留 |
| 移动操作 | 地图点线选择、框选/面选、上报、模拟阀门、本人任务 | 触控可用、返回正确、后台不继续计时，无真实设备命令 |
| 视频 | 两个本地在线通道、一个离线通道 | 实际播放，离开停止，缺失资源有失败反馈 |
| 文件 | CSV 与快照导出，重新导入快照 | H5 下载文件；App 显示私有目录路径；导入后数据恢复 |
| 显示与性能 | 真机横竖屏、冷启动、30 分钟操作 | 没有遮挡和持续资源增长；记录实际机型、系统、分辨率和耗时 |

以上待外部环境的步骤由实际执行结果填写验收表，不根据编译通过推断成功。
