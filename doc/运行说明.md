# 最简运行说明

## 1. 环境

- JDK 17
- Maven 3.9+
- Node.js 18+
- MySQL 8.x
- MySQL 账号密码：`root / root`

不需要 Redis，不需要安装 JWT 或配置 Spring Security。

## 2. 启动 MySQL

确认 MySQL 服务已经运行。数据库 `charging_platform` 不存在也没关系，后端连接参数包含自动创建数据库配置。

## 3. 启动后端

PowerShell：

```powershell
cd 'E:\bishe27\springboot-vue-mysql-android\汽车充电桩可视化信息平台\springboot'
mvn.cmd spring-boot:run
```

Git Bash：

```bash
cd '/e/bishe27/springboot-vue-mysql-android/汽车充电桩可视化信息平台/springboot'
mvn spring-boot:run
```

启动成功后验证：<http://localhost:8080/api/home/overview>

也可以在 IDEA 中运行：

```text
Main class: com.charging.platform.ChargingPlatformApplication
Program arguments: 留空
Environment variables: 留空
```

如需开启每 15 分钟一次的自动状态模拟，在 IDEA Environment variables 中填写：

```text
SIMULATION_ENABLED=true
```

默认关闭自动模拟；后台工作台的“运行一次状态模拟”按钮始终可用。

## 6. 常见问题

- `Access denied for user root`：检查 MySQL 密码是否为 `root`。
- 端口 8080 被占用：关闭原 Java 进程或修改 `application.yml`。
- PowerShell 禁止运行 `npm.ps1`：使用 `npm.cmd run dev`。
- 地图空白：确认 `vue/public/config/amap.txt` 存在并可访问 `/config/amap.txt`。
- 页面接口失败：先打开后端 overview 地址，确认后端和 MySQL 正常。
