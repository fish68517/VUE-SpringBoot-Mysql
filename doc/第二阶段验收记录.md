## 4. 稳定性与性能

30 分钟 H5 连续运行检查通过，实际运行 1802 秒，保存 35 次资源观测，页面及请求错误为 0。完整记录见 `code/unpackage/evidence/phase2/stability.json`。

| 实测项 | 结果 |
| --- | --- |
| 登录后大屏首次可见 | 345 ms |
| 缓存后返回大屏最长耗时 | 59 ms |
| 正式观察中保留堆内存范围 | 11.06—11.76 MB |
| 结束时保留 DOM / 监听器 | 2388 / 441；观察中保持稳定 |
| 大屏 Canvas | 固定 2 个 |
| 浏览器文档 | 1 个 |
| 测试前后发行版本 | 首页 SHA-256 一致 |

上述结果通过脚本设置的保留堆、DOM、监听器和 Canvas 阈值检查，不代表所有平台不存在内存增长。H5 加载耗时是本机自动化实测；未对所有按钮逐一测量 300 ms 指标，也未测量 Android 真机冷启动 5 秒目标。

检查在同一浏览器上下文反复切换轨迹、视频、地图和大屏，验证离开页面后播放器释放、大屏 Canvas 数量固定，并使用浏览器性能指标比较强制 GC 后保留的堆、DOM 和监听器。检查前后核对 H5 首页哈希，确保测试期间没有换构建版本。该测量不替代 Android 冷启动、系统返回键和后台恢复测试。
