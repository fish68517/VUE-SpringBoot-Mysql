## 下次如何更新

日常修改仍以根 `dist/` 和根 `uniCloud-aliyun/cloudfunctions/zsh-ledger-api/` 为主源码。部署前同步到标准工程，再上传。不要只改部署副本。

在本项目根目录打开 PowerShell，执行：

```powershell
$hxCli = 'D:\soft\HBuilderX.5.24.2026081301\HBuilderX\cli.exe'
$deployRoot = Join-Path $PWD.Path 'tools\zsh-ledger-deploy'

# HBuilderX 保持登录；关闭外层工程，避免父子工程同时打开造成定位异常。
& $hxCli project close --path $PWD.Path
& $hxCli project open --path $deployRoot

# 同步最新源码。
Copy-Item -Path '.\uniCloud-aliyun\cloudfunctions\zsh-ledger-api\*' -Destination (Join-Path $deployRoot 'uniCloud-aliyun\cloudfunctions\zsh-ledger-api') -Recurse -Force
New-Item -ItemType Directory -Path (Join-Path $deployRoot 'web') -Force | Out-Null
Copy-Item -Path '.\dist\*' -Destination (Join-Path $deployRoot 'web') -Recurse -Force

# 确认云函数输出“上传完成”和 OK 后，才继续发布网页。
& $hxCli cloud functions --upload cloudfunction --prj zsh-ledger-deploy --provider aliyun --name zsh-ledger-api
& $hxCli hosting deploy --prj zsh-ledger-deploy --space mp-f4c892a2-7540-459d-9a6f-ccae78f87037 --provider aliyun --source web
```

以上同步会覆盖同名文件，不会清除暂存目录中已从主源码删除的文件；若未来删除文件，应核对并同步清理对应暂存文件。本次暂存目录为新建，12 个文件与 `dist` 一致。

HBuilderX CLI 在部分失败情形下仍返回进程退出码 0，不能只看 `$LASTEXITCODE`，必须阅读输出的完成/失败信息。云函数和网页均成功后，让三个账号关闭旧页面重新打开，必要时按 `Ctrl+F5` 强制刷新。

本次排查发现：同时打开外层普通网页项目与嵌套标准工程时，云函数上传未正常结束；取消该次上传并关闭外层项目后，重试立即成功。因此当前 HBuilderX 保留的是 `zsh-ledger-deploy` 部署工程。源码文件没有被关闭项目操作删除。

部署副本 `web/` 已被部署工程的 `.gitignore` 排除；标准工程 `manifest.json` 和模板可提交，便于后续复用。`.hbuilderx/` 的本机关联信息不提交；换电脑后，在标准工程中重新关联上述原空间即可。
